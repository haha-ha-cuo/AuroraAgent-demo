# 项目简介

本项目旨在制作一个**形如 CodeX 的全平台桌面 AI Agent 应用**：用户把项目交给 Agent，Agent 会自主规划、委派并完成开发任务。

## 它解决什么问题

传统的编码助手以“单轮对话 + 单点补全”为主，而本项目要交付的是一个**可长时间自主运行的项目级 Agent**：

- 拿到一个项目后，不是回答问题，而是**推进任务直至完成**；
- 复杂任务被拆解并**委派给子 Agent**，而非在一个上下文里硬塞；
- Agent 能根据任务难度**自行权衡投入的推理强度**，在成本与质量之间取得平衡；
- 用户可以通过对外接口**特化 Agent 的能力**，让它更贴合自己的代码库与工作流。

## 与 CodeX 的对照

| 维度 | CodeX | 本项目 |
| --- | --- | --- |
| 形态 | CLI / 云侧编码代理 | **全平台桌面应用** |
| 任务组织 | 任务分解与工具调用 | **树形委派**：根 Agent → 子 Agent |
| 推理强度 | reasoning effort 分档 | Agent **自决**委派质量档位 |
| 能力扩展 | 工具 / MCP | 工具 / MCP + **能力特化层接口** |
| 部署 | 云端为主 | 本地运行时 + 桌面壳 |

> 说明：上表为定位对照，非功能逐项对齐。CodeX 是 OpenAI 的编码代理产品，本项目为独立实现。

## 关键概念

- **根 Agent（Root Agent）**：接收用户项目与目标，负责顶层规划与任务拆解。
- **子 Agent（Sub Agent）**：承接根 Agent 委派的具体子任务，可继续向下委派，形成树。
- **委派质量 / 推理强度**：Agent 决定每次委派时投入的推理档位。
- **能力特化层**：对外暴露接口，让用户自定义上下文、工具、提示与检索策略。

更完整的概念与设计见[架构设计](../architecture/overview.md)。
