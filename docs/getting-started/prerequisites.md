# 环境准备

从源码运行 AuroraHarness 的浏览器界面，需要：

| 工具 | 要求 |
| --- | --- |
| [uv](https://docs.astral.sh/uv/) | 管理 Python 与依赖 |
| [Node.js](https://nodejs.org/) | 24.x，至少 24.11 |
| [pnpm](https://pnpm.io/) | 11.x |
| [Git](https://git-scm.com/) | 获取源码 |

Python 由 uv 按项目要求选择，无需另建虚拟环境。

构建桌面版时，再安装 Rust 与对应平台的 Tauri 开发依赖。只运行浏览器界面无需 Rust。

下一步：[快速开始](demo.md)。
